# История изменений

## 0.2.0 — 2026-11-18

### Изменения, требующие внимания при обновлении

- Для новых задач включено автоматическое агентское ревью. Решение о приёмке остаётся за назначенным приёмщиком. Для задач с ручным ревью укажите `--agent-review-policy manual` при создании.
- Завершение задачи удаляет её worktree до закрытия таба Herdr. Worktree сохраняется, если он используется другой незавершённой задачей.

### Добавлено

- Команда `update` и навык `control-update` для обновления установленной программы из релиза GitHub или локального checkout.
- Компактный статус панели и вывод текущего результата задачи для управляющего агента.
- Пользовательское руководство на GitHub Pages с инструкциями по установке, первому запуску и настройке.

### Изменено

- CLI показывает версию релиза для сборки с тегом и идентификатор коммита для сборки из checkout.
- Запуск задач и подготовка ревью передают меньше повторяющегося контекста.

### Исправлено

- Проверка свежести ревью продолжает работать после завершения задачи и удаления её worktree.
- Публикацию можно восстановить после rebase, если проверенное изменение сохранилось.
- Технически прерванное ревью можно возобновить с явного разрешения пользователя.

## 0.1.0

Первый публичный выпуск CLI и MCP для управления задачами. Установочные пакеты для Linux и macOS ARM64.
