# Вопросы и продолжение

Вопрос задай в текущем чате, через инструмент вопросов, если он доступен.
Продолжай независимую работу; зависимую — после ответа. Для обычного уточнения
block и questions.json не нужны.

Если пользователь просит отложить обсуждение, сохрани план по
[planning.md](planning.md), затем выполни командой выбранного экземпляра:

```sh
block --run RUN_ID --question 'Точный вопрос' --checkpoint 'Сделано, изменения, проверки, путь к плану, следующий шаг'
```

block записывает checkpoint.md и его путь в questions.json и отправляет
уведомление. Запись сохраняется и при сбое уведомления. После block заверши
ход: не жди в цикле и не продолжай автоматически.

При следующем взаимодействии покажи отложенный вопрос в чате. Управляющий
сохраняет ответ через `answer TASK --text 'Ответ'`, снимая блокировку.
Команда не отправляет новый ход. По поручению пользователя исполнитель читает
questions.json и checkpoint и продолжает в том же табе с тем же RUN_ID и worktree.
Если исполнитель исчез, сначала сверь состояние и восстанови его по файлам
и [recovery.md](recovery.md); исчезновение процесса не означает готовность.
