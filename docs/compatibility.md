# Матрица приёмки

Экспериментальный выпуск: целевая матрица Linux/macOS × Codex/Claude Code.
Полная поддержка этой матрицы пока не подтверждена. Windows, распределённый
state, Gemini и native resume не входят в эту сборку.

| Окружение | Автотесты | Цикл с реальным CLI |
| --- | --- | --- |
| Linux + Codex | Локально, fake herdr и временный Git | Цикл no-code прошёл; полный code/recovery ещё требуется |
| Linux + Claude Code | Локально, fake herdr и временный Git | CLI недоступен при подготовке |
| macOS + Codex | CI подготовлен, локально не запускался | macOS недоступна |
| macOS + Claude Code | CI подготовлен, локально не запускался | macOS и CLI недоступны |

Claude-адаптер экспериментальный до приёмки с реальным CLI. Минимальная проверяемая
версия Python — 3.10; CI также проверяет 3.13. При подготовке доступен клиент
Python 3.14.7, Git 2.56.0, herdr 0.9.3 и Codex 0.161.0. Изолированный тестовый сервер запущен тем же herdr 0.9.3;
минимальные версии интеграций этим не определяются. Перед публикацией зафиксируй ОС, архитектуру CPU, Python,
Git, клиент/сервер herdr и CLI каждого агента по фактическим успешным прогонам.

При подготовке публикации повторно проверены установка в пустой временный
каталог, doctor/environment, ссылки восьми скиллов и создание синтетических
записей проекта/задачи: Linux x86_64, Python 3.14.8, Git 2.56.0,
herdr CLI 0.9.3, Codex CLI 0.164.0. Новый сервер и агенты в этой проверке
не запускались; версии CLI проверены через --version. Этот прогон не заменяет
приёмку обнаружения скиллов агентом и полного цикла с реальным CLI.

Для каждой ячейки в отдельной named session с отдельными state/config/bindings:
установка; обнаружение восьми скиллов; no-code open; повторный и конкурентный
open; progress; block/checkpoint; answer и продолжение в том же табе; finish;
review; complete и закрытие собственного таба. Затем code worktree, main без
origin, main с origin, branch с origin, отказ push, merge conflict и отмена.
Проверь два проекта/агента, разные session identity, отказ чужому namespace,
длинный вывод, неизвестный исход timeout и файловое восстановление без дубля.

Сохрани логи без credentials, артефакты и отметки каждой проверки.
Непройденная ячейка блокирует объявление полной поддержки целевой матрицы.

Проверенный no-code цикл Codex: plan/progress → block/checkpoint → answer →
продолжение в том же табе → finish/review → complete/done с закрытием тестового таба.
Уведомления из sandbox получили PermissionDenied; файлы и статусы сохранились.
Обнаружение скиллов реальным CLI, code/recovery/длинный вывод ещё требуют проверки.

## Выборочный вывод

Без новых флагов task-create, task-set, run, memory-list и review-show сохраняют
прежние формы JSON. --compact у первых трёх сокращает вывод и указывает команду
подробностей. review-show --latest возвращает attempts с последней попыткой;
свежесть всех попыток одного просмотра вычисляется по одному текущему снимку.
Пустая история не требует снимка. memory-list --limit N [--offset N] возвращает
items, total и next_offset, сортируя по created_at и ID от новых к старым.
Без --limit порядок и полный список остаются прежними.

review-read читает существующие фиксированные снимки и не создаёт попытку или
аренду. Его разделы и границы описаны в [agent-review.md](agent-review.md).
Полный снимок, формат версии, проверка всех blobs при claim/conclude и полномочия
приёмщика сохранены. Краткий entry не заменяет проверку необходимых материалов.
