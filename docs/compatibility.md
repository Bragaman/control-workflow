# Матрица приёмки

Экспериментальный выпуск: целевая матрица Linux x86_64/ARM64 и macOS ARM64
(Apple Silicon) × Codex/Claude Code. macOS Intel исключён из CI и новых поставок.
Полная поддержка этой матрицы пока не подтверждена. Windows, распределённый
state, Gemini и native resume не входят в эту сборку.

Автотесты используют fake herdr и временный Git; они не подтверждают работу
реального CLI агента. Ранее на Linux пройден no-code цикл с Codex. Полный
code/recovery и обнаружение скиллов реальным клиентом требуют отдельной приёмки.
Для Claude Code нет подтверждённого полного цикла; адаптер экспериментальный.
Native CI настроен на три целевые платформы; наличие workflow не подтверждает
успешный прогон конкретного кандидата. Локальная проверка Linux не подтверждает macOS.

Результаты, версии и ограничения прогонов сохраняются в артефактах задач вне
исходников. Перед публикацией или объявлением поддержки фиксируй ОС, CPU, Git, версии клиента
и сервера herdr и CLI каждого агента по фактическим успешным прогонам.
Python 3.10+ нужен только для тестов и аудита. Очистка worktree выполняется Git
без Python, sudo и lsof.

Для каждой ячейки в отдельной named session с отдельными state/config/bindings:
установка; обнаружение всех поставляемых скиллов; no-code open; повторный и конкурентный
open; progress; block/checkpoint; answer и продолжение в том же табе; finish;
review; complete и закрытие собственного таба. Затем code worktree, main без
origin, main с origin, branch с origin, отказ push, merge conflict и отмена.
Проверь два проекта/агента, разные session identity, отказ чужому namespace,
длинный вывод, неизвестный исход timeout и файловое восстановление без дубля.

Сохрани логи без credentials, артефакты и отметки каждой проверки.
Непройденная ячейка блокирует объявление полной поддержки целевой матрицы.

## Выборочный вывод

Без новых флагов task-create, task-set, run, memory-list и review-show сохраняют
прежние формы JSON. --compact у первых трёх сокращает вывод и указывает команду
подробностей. `run --compact` и `open` для результата возвращают ограниченный
`result_summary` без истории попыток и выдержек отчёта; прежние подробности
остаются в полном `run`. Ошибки ограничиваются по длине и сопровождаются ссылкой
на полный источник. review-show --latest возвращает attempts с последней попыткой;
свежесть всех попыток одного просмотра вычисляется по одному текущему снимку.
Пустая история не требует снимка. memory-list --limit N [--offset N] возвращает
items, total и next_offset, сортируя по created_at и ID от новых к старым.
Без --limit порядок и полный список остаются прежними.

review-read читает фиксированные снимки без создания попытки или аренды:
[протокол ревью](agent-review.md). Приёмка и очистка worktree описаны в
[git-policy.md](git-policy.md); прежний complete --keep-worktree удалён из CLI/MCP.
