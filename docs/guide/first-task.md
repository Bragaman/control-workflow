# Первая задача

Начните с задачи без изменения кода. Так можно проверить запуск агента и приёмку,
не затрагивая рабочий репозиторий. Предполагается, что [панель установлена](installation.md)
и управляющий запущен в herdr.

## Создайте проект и задачу

Отправьте управляющему:

> Создай проект demo для пробных задач. Добавь задачу: подготовить краткий список
> проверок перед началом рабочего дня. Критерии: пять пунктов. Описать проверки,
> не выполняя их. Настройки не менять. Работа без кода, независимое ревью auto. Пока не запускай.

Управляющий создаст записи проекта и задачи. Проверьте цель и критерии в его ответе.
Проект хранит общий контекст; задача — конкретный ожидаемый результат.

## Запустите выбранную задачу

> Открой задачу с этим ID.

Панель откроет отдельный терминал исполнителя. Он получает задание, составляет план
и сохраняет результат. Открытие задачи не означает ожидание её завершения:
управляющему можно поручить другую работу.

## Проверьте результат

> Покажи прогресс и результат этой задачи.

Если исполнителю нужен ответ, дайте его через управляющего. После сдачи в режиме auto
результат проверит независимый агент. Review — статус задачи, passed — заключение независимого проверяющего. Даже после
passed задача остаётся в review до вашей приёмки.

Если результат не подходит, назовите конкретные исправления и попросите продолжить задачу.

## Примите работу

> Прими и заверши эту задачу.

Панель выполнит приёмку и закроет терминал задачи. Отчёт и история запуска сохранятся.
Для задачи с кодом приёмка также выполняет выбранные Git-операции.
Перед приёмкой проверьте [режим Git и правила удаления worktree](workflow.md#git).
