# План задачи

Покажи сформулированный план в чате до работы, чтобы пользователь мог его
скорректировать. Учти правки; при изменении порядка или объёма покажи обновление.
Сохрани план перед выполнением, откладыванием или передачей. Разрешение на запуск
определяется поручением пользователя: запускай только явно выбранные задачи.

Пути относятся к выбранному state из [control-entry.md](control-entry.md):

- до первого запуска — `tasks/TASK_ID/plan.md`;
- при наличии запуска — `runs/RUN_ID/plan.md`.

Создай каталог при необходимости; JSON состояния меняй только через control.py.
Верни пользователю ссылку на файл. План содержит цель, оставшиеся шаги, критерии
готовности и открытые вопросы; отдельно укажи решения, требующие ответа.
Завершённые подробности и причины решений сохраняй в связанных артефактах,
оставляя в плане ссылки и влияющие на продолжение условия. Объём определяется задачей.

Исполнитель сначала читает plan.md текущего запуска, иначе план задачи,
и сохраняет актуальную версию в текущий запуск. При повторном запуске сначала
проверь план и checkpoint предыдущего. При передаче сообщи получателю путь к плану.

Перед block сохрани план, а в checkpoint — текущее состояние, неоконченные
изменения, проверки, следующий шаг и ссылки на план и подробные артефакты.
Копировать всю историю не нужно. Для отложенной задачи без запуска достаточно
плана задачи; создавать запуск ради файла не требуется.
