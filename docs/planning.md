# План задачи

Как только план сформулирован, покажи его в текущем чате, чтобы пользователь
мог прокомментировать шаги до выполнения. После правок покажи обновлённый план.

Сохрани актуальный план на диск:

- перед началом работы по нему, если у пользователя нет комментариев;
- когда задачу решено выполнить позже;
- перед передачей задачи другому агенту.

Учти полученные комментарии перед сохранением. Отсутствие комментариев само
по себе не даёт полномочий на запуск: работай в рамках поручения пользователя,
запускай только явно выбранные задачи. Черновик во время обсуждения можно
показывать в чате без отдельного файла.

Пути ниже относительны к выбранному state (см. [control-entry.md](control-entry.md)).
До первого запуска сохраняй план в `tasks/TASK_ID/plan.md`. Если запуск уже
есть, сохраняй в `runs/RUN_ID/plan.md`. Создай каталог, если нужно; JSON-состояние
задачи меняй только через `scripts/control.py`. Укажи цель, шаги, проверки
готовности и оставшиеся вопросы; выдели решения, для которых ещё нужен ответ.
Верни пользователю ссылку на сохранённый файл.

При передаче укажи получателю путь к плану. Исполнитель до начала работы читает
`tasks/TASK_ID/plan.md`, если в текущем запуске ещё нет `plan.md`, и сохраняет
актуальную версию в `runs/RUN_ID/plan.md`. При повторном запуске сначала проверь
план и checkpoint предыдущего запуска. Дальше обновляй план текущего запуска
при изменении шагов и показывай изменения порядка и объёма работы в чате.

При откладывании текущего запуска сохраняй план до `block`, а в checkpoint
укажи путь к нему и следующий шаг. Для задачи без запуска достаточно файла
плана; создавать запуск ради сохранения не требуется.
