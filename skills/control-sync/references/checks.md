# Источники проверки

Выбирай проверки из реально описанных ресурсов; этот список не добавляет новые
ресурсы в охват. Используй существующие доступы и клиентские утилиты. Команды
ограничивай по времени, ответы — нужными полями. Секреты, окружение процессов,
полные конфиги с credentials и полные журналы в артефакты не выводи.

| Источник | Проверка чтения | Что она подтверждает |
| --- | --- | --- |
| Панель | show projects/tasks, run; нужные state/checkpoint/result | Сохранённое состояние и договорённости, не состояние службы |
| Локальный Git | rev-parse HEAD, status --short, worktree list --porcelain; ссылка/каталог из проекта | Локальный commit, изменения и worktree. Локальная remote-tracking ветка не доказывает состояние remote; при необходимости git ls-remote для выбранного ref |
| herdr | Сначала herdr --help, затем чтение указанной в запуске сессии/workspace/tab/pane | Наличие и идентичность исполнителя. Проверяй namespace из state, а не текущий фокус. При необходимости читай только релевантный участок терминала с маскировкой секретов |
| SSH-хост | BatchMode=yes, ConnectTimeout=5, строгая проверка ключа; hostname и нужная команда чтения | Доступность указанного хоста и результат команды. Ошибка SSH не доказывает выключение хоста |
| systemd / контейнеры | systemctl is-active/show выбранной службы; docker/podman inspect с выборкой State/Health | Состояние процесса/health. active не доказывает работоспособность внешнего маршрута |
| HTTP/API | Ограниченный GET штатного health/status или нужного ресурса, с существующей авторизацией | Код и нужные поля ответа конкретного маршрута. 401/403 — ограничение проверки, 404 требует проверки маршрута и прав |
| Файлы / ссылки | Проверка существования, разрешения symlink, нужные поля конфигурации без секретов | Наличие и содержимое на проверенном хосте; отсутствие в локальном checkout не доказывает отсутствие развёртывания |

Не меняй trusted hosts, firewall, учётные записи или сервисы ради проверки.
Для запрета сокета/сети используй штатное разрешение вне песочницы, если оно
доступно; при отказе сохрани источник как непроверенный и продолжи обход.
Успешная проверка нижнего слоя подтверждает только этот слой: для сервиса
сопоставь процесс, endpoint и актуальные критерии задачи, насколько позволяет
доступ. Проверка права на вход требует отдельного разрешения, если она меняет
группы, учётные записи или сессии.

Для наблюдения достаточно записи:

```text
Объект: PROJECT / ресурс / свойство
Описан: путь и раздел документа или ID задачи/памяти
Проверено: ISO-8601 с часовым поясом
Источник: команда/путь/endpoint без секрета
Наблюдение: нужные поля ответа
Вывод: подтверждено / непроверено (причина) / неоднозначно (вопрос)
Изменение: файл или команда панели; прежняя запись памяти при замене
```
