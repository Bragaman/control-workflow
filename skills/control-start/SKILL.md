---
name: control-start
description: Открыть или запустить выбранные пользователем задачи контрольной панели.
---

Если контракт экземпляра ещё не прочитан, читай
[control-entry.md](../../docs/control-entry.md).
Открой явно выбранные задачи одной командой `open TASK…`. До нового запуска
проверь назначение, сложность и профиль по [task-profile.md](../../docs/task-profile.md).
Сформулированный план сохрани по [planning.md](../../docs/planning.md);
если плана ещё нет, его составляет исполнитель.

Покажи статус, цель, действие и таб каждой задачи. Для launching покажи RUN_ID
и путь state.json: таб создаётся подготовителем. Не жди выполнения агента.
open переиспользует работающего исполнителя, восстанавливает подтверждённый старт
или создаёт запуск после проверки отсутствия прежнего. blocked возвращает
вопрос; review/done/cancelled — результат. Модель работающего исполнителя сохраняется;
профиль задачи применяется при следующем запуске.
Для разового выбора используй open TASK --profile NAME (также start --profile).
Он влияет только на новый запуск. Несовместимый запрос для работающего исполнителя
возвращает ошибку; сохрани checkpoint и явно подготовь новый запуск для смены.

При action=error прочитай [recovery.md](../../docs/recovery.md) и файлы указанного
запуска. Для blocked используй протокол [questions.md](../../docs/questions.md).
Сообщение о запуске или продолжении начинай с `TASK_ID: `.
