---

Прочитай [выбор экземпляра](../../docs/control-entry.md) и
[общую Git-политику](../../docs/git-policy.md).
По явному поручению пользователя выполни `git-publish TASK`;
для новых изменений добавь `--commit-message` с конкретным английским описанием.
При явном делегировании назначенному reviewer передай `--by REVIEWER`.
Нужен результат в review; обязательное auto-ревью должно быть актуальным и passed.

Покажи статус задачи, сохранённые ветки и commits из git_completion.
Ошибка сохраняет работу: устрани причину и повтори git-publish.
После доработок снова сдай результат через finish и выполни нужное ревью.
Publish сохраняет исполнителя, таб, ревьюеров и worktree.
Окончательная приёмка — отдельное поручение для
[control-complete](../control-complete/SKILL.md).
