---
name: control-update
description: Проверить или обновить установленную программу control-workflow из локального checkout или GitHub Releases.
---

Определи экземпляр по [control-entry.md](../../docs/control-entry.md) и проверь
`environment`: program-root, state, config и bindings. Уточни источник и версию,
если они не следуют из запроса или известной конфигурации. Для обновления из
исходников используй выбранный checkout; сохранённый worktree задачи не считай
постоянным checkout. Прочитай раздел «Обновление» в [install.md](../../docs/install.md).

Для проверки версии установленной программы используй её абсолютный путь и
`update --check`; для указанного выпуска добавь `--version`. Если эта команда в
старой версии отсутствует, следуй переходному порядку из install.md. Проверка
версии сама по себе не устанавливает обновление.

По поручению обновить сначала обеспечь описанное в install.md безопасное окно:
остановку новых запусков и завершение команд запуска/приёмки и текущих ходов
исполнителей. Если окно не подтверждено, сообщи, что осталось сделать, и не
переключай программу. Вызывай `scripts/install.sh --prefix PROGRAM_ROOT` из
выбранного checkout либо установленный `bin/control-workflow update` для release;
для конкретного выпуска передай `--version`. Сохраняй внешний state/config/bindings.

Проверь результат команды, версию установленного бинарника и путь backup;
покажи их пользователю вместе с источником и ограничениями проверки. Уже
запущенные процессы продолжают работать со старым бинарником. При ошибке
остановись, сохрани вывод и следуй порядку восстановления из install.md.
При наличии запуска сохраняй отчёт по [worker.md](../../docs/worker.md).
